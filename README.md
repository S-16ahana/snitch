# Snitch

Snitch is a clothing e-commerce application built with the MERN stack.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- express-validator

## Current Features

- User registration
- Password hashing with bcrypt
- JWT access token generation
- JWT refresh token generation
- User roles: User and Seller
- Request validation with express-validator
- MongoDB database connection
- Product and cart requirements defined
